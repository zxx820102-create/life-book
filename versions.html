谱系的规律

每一步都不推翻上一步，只长出下一个器官

书的定义逐版扩张——文本 → 响应体 → 社区 → 感官 → 辩论场 → 本体 → 课本 → 基础设施 → 记忆器官。
这就是"丝滑"：无跳变，每一版是上一版的自然成熟。

过去各枝蒸馏自主书版本记录（v3.0 书末·版本史）；未来各枝取自《终局推演书》§1 版本谱系（2026-08-20），其认识纪律：工程外推（高）→ 趋势推演（中）→ 文明推演（低）→ 宇宙推演（METAPHOR），置信度逐档递减且全部显式标注——所以它们画成虚枝，且越远越淡。

按书的宪法：终态不是静态全知，而是永远保留下一次合法纠正的稳定生成过程。这棵树永远为下一片叶留着位置——包括你将参与的那一片（共同写作）。
