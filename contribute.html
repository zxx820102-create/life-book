共创宣言

这本书的成长，从今天起交到更多人手里

这本书从 v0.9 到 v3.0，由一小群人写成；从 v4.0 起，它属于每一个愿意认真对待生命知识的人。你的一处勘误、一次心跳、一门语言，都是它的新年轮。写作不再有门槛，只有一条共同的纪律：诚实。

—— v4.0 共创宣言 · 2026

为什么是"世代书"？因为一棵树长得过一棵草的秘密，不在于第一年，而在于每一年的年轮都长在前一年的年轮上。这本书从 v0.9 的十三章长到 v3.0 的七部活书，靠的是同一群人一圈圈地长；要长到一百年，就必须让更多的手接过年轮。

四条通道按门槛递升：从三十秒的心跳，到数周的语言翻译，到受邀成为章节共同作者。任何一条通道的任何一步，都真实地影响下一版。

四条通道

从一颗心，到一章书

四条通道，门槛递升，互相衔接：心跳数据告诉我们哪里没讲明白，勘误让文本更诚实，翻译让书抵达更多母语，共著让新的章节长出来。你可以在任何一层停下，也都算数的。

通道 ③

译者

门槛：数周 · 认领一门语言
v0.9.1 的先例：英文版上线当天，我们删掉了语言条款——一本书不该规定读它的人说什么语言

书是单文件 HTML（无外部依赖，双击即读），译本保持同构：只译文字，不动结构、样式与脚本。先认领一门语言（避免两个人译同一门），再按下面的本地化指南开工。

English ✓（v0.9.1 已上线） Español 待认领 Français 待认领 العربية 待认领 हिन्दी 待认领 Português 待认领 Русский 待认领 日本語 待认领 한국어 待认领 Swahili 待认领 …… 所有语言

认领方式：走通道②提交一条"我要译 X 语"，致谢墙即刻为你留位；译本以 life-book-<lang>-vX.html 命名，进入版本树的枝头。

📘 data-slot 本地化指南（认领后照此开工）
  1. 复制底本：以最新主书（如 life-book-public-v4.0-wip.html）为底本另存，不要在原文上改。
  2. 标记可译槽位：给每个需要翻译的元素加 data-slot 属性，槽位名用「章节.部位」命名，全书唯一：
    3. <h2 data-slot="ch1.title">你从哪里来：一座用星星搭的城</h2> <p data-slot="ch1.p1"><strong>你身体里的每一块砖…</strong></p>
  3. 只译槽位内的文字：类名、id、结构、<style>、<script> 一律不动；data-slot 值保持原文不变——它是各语言版本之间对齐的锚点，也是未来 v7.0 万物书（机器可读版）的地基。
  4. 四样东西不许意译：①红旗症状词表（27 组急症触发词的译名须经医者校过）；②数字与单位；③认识状态标签（FACT / MODEL / HYPOTHESIS / UNKNOWN 可加注音译，不可删）；④"红旗优先律"的执行顺序。
  5. 文化适应三问：这个比喻在你的语言里成立吗？（不成立就换一个等价比喻，并保留原文于注释）；本地有哪些"该签未签的致谢名单"值得补进卷三？当地急救电话号码需要本地化提示吗？
  6. 双主题自查：译完用夜读模式过一遍——德文长词与阿拉伯文从右到左的排版都可能在窄栏里破版，破版处加 lang 与 dir 属性。
  7. 提交：走通道②提交"译本 X 语 v1 完稿"，两位读者试读（可由你组织）后挂入版本树，你进入致谢墙"译者"一栏。

体量诚实预告：全书约 8 万汉字。可以只译一卷（比如先译卷七《时间之河》——死亡教育在多数语言里都是最缺的），卷为单位认领也欢迎。

通道 ④

章节共同作者

门槛：高质量贡献 3 次后 · 受邀加入
邀请制不是精英制——它只是保证：改这本书的人，先读过这本书

当你的高质量贡献累计 3 次（勘误被采纳 / 心跳洞察被版本记录引用 / 译本成稿，任意组合），你会收到加入编辑层的邀请，成为某一章或某一卷的共同作者，参与新章的撰写与旧章的重写。

编辑协议（受邀后生效的六条工作纪律）：

📖 编辑协议全文
  1. 一 hunk 一操作：一次编辑只改一处，改前先读原文，改后即校验——原子提交，永远可回滚。
  2. 证据随行：新的事实句必须带来源与认识状态；没有来源的观点不进正文，可进"缺口账本"。
  3. 历史不可原地改写：被推翻的结论移入"智慧边界"附录并保留推翻过程，不悄悄删除。
  4. 红旗一票：任何编辑者对涉及急症安全的文字有即时否决权——先保守，再讨论。
  5. 署名与致谢：实质改写署"共同作者"，勘误与翻译入致谢墙；删除他人署名需要全部当事人同意。
  6. 每版必录：任何改动进入版本史一行：改了什么、为什么、谁提的——版本树是这本书的发育史，不许有断年轮。

第一块基石就是这一页：它本身就是一个共创工件——发现它的错，就用通道②告诉我们。

贡献者宪章

六条 · 与全书宪法同源

主书"书末·诚实边界"立了全书的认识纪律；这一节把它翻译成对写作者的纪律。所有通道的每一份贡献，都默认遵循：

一

诚实分层

每句新内容标认识状态：FACT / MODEL / HYPOTHESIS / UNKNOWN / 类比——不把比喻当证据，不把假说讲成定论。书里的比喻为了三秒懂一个系统；证据才帮决策。

二

红旗优先

涉及急症症状的文字，第一句永远是就医指引，解释放后面。任何人不得稀释、绕过或"软化"27 组红旗触发词——这一条在编辑协议里是一票否决。

三

比喻准确

"身体是城市"帮理解，但不构成证据。新比喻必须给出边界（它在哪里成立、在哪里失效）；替换旧比喻时，说明为什么新的更好。

四

不冒充诊疗

本书是健康科普，不替代医疗诊断与治疗。贡献者不以书的名义回答"我该吃什么药"类个体诊疗问题——那一问的诚实答案是：请就医。

五

署名尊重

采纳即署名（除非你要求匿名）。引用传统知识先致谢来源民族与文本——卷三立过先例：致谢名单上第一个名字，是北美原住民。不删前人署名。

六

纠错永续

错误不掩盖、历史不原地改写：版本树留痕，被推翻的结论进"智慧边界"而不是消失。纠错的通道永远开着——包括对这份宪章本身的纠错。
