感知总览

这一页，是这本书的神经末梢

一棵树不知道哪根枝该长，因为它感觉不到风。一本书不知道哪章该改，因为它听不见读者在哪里停住。这一页就是书的感受器：它聚合两类本地信号——你在各章末点过的"💔 看不懂"心跳，与你在伴读里问过、书还没能回答的问题——把它们显影成"我们此刻最不懂什么"。

这些就是书下一步要长大的方向。

—— v5.0 感知宣言 · 2026

感知数据流 读端（本设备 localStorage，零联网） ├─ 心跳键 lb-heartbeats-v1 [{ch, type: useful|act|confused, t}] ← 主书各章末三颗心 └─ 未命中键 lb3-unans [{q, t}] ← 伴读"还没讲到"的问题 ↓ 聚合 ├─ type=confused 按章节聚类 → 「读者最不懂 TOP 榜」 ├─ 全部心跳逐条显点 → 「心跳点阵」（💔 高亮） ├─ 未命中问题全文 → 「未命中问题榜」+ 关键词频率 → 「问题词云」 └─ 聚合快照可导出 JSON（剪贴板）→ 交给 XYZ 端做跨设备显影 ↓ 输出 写端（本设备剪贴板） ├─ 「提交新证据」表单 → JSON → 剪贴板（与共同写作页同机制） └─ 未来：SENSORS 加行接入文献 RSS / 期刊 alert / 心跳端点 → 书开始自己长大

隐私：这一页不发出任何网络请求（可在离线状态打开验证）。所有数据只存在这台设备的浏览器里；导出与否，完全由你决定。

感知输入

  
当书连上世界的数据流，它将开始自己长大

  
现在这一页只听本设备的心跳与疑问（下方第一个传感器，已激活）。文献与期刊的传感器已经在接口里预留好位置——未来每加一行、接上一个数据流，书就能自己发现"世界又长出了新证据"。

  

  
SENSORS 是这一页的感知输入接口：每行一个传感器（id / 类型 / 状态）。状态为 active 的会实时参与本页显影；planned 的等一个数据流地址——接线那天，书的神经末梢就伸到了全人类的文献海里。
